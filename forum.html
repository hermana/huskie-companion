How do I center a <div> horizontally and vertically?

asked by codedaisy • 12 votes • 3 replies • tags: css layout flexbox
Question • posted 2 hours ago

I need to center a child <div> inside a parent both horizontally and vertically. What’s the simplest modern CSS approach?

Answer by frontendluke • accepted
.parent { display: grid; place-items: center; min-height: 200px; }
.child { width: 200px; height: 100px; }

Using CSS Grid with place-items: center is concise and widely supported.

Answer by cssfan
.parent { display:flex; align-items:center; justify-content:center; }

Flexbox is also great and works even when you don’t know the child size.

Comment by codedaisy

Thanks! Grid did the trick.
